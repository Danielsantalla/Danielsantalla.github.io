# Daniel Santalla portfolio

Independent static portfolio hosted on GitHub Pages at https://danielsantalla.com. No build step or ChatGPT runtime dependency. Publish main branch root; .nojekyll keeps the static export unchanged.

All videos, fonts and images are local to this repository. No API tokens or fictitious social metrics are included. Legacy aliases use HTML redirects because GitHub Pages does not support custom server-side301rules.

All rights to artwork and media remain with their respective owners. No open-source license is granted.

The social integration and operating instructions are documented in [docs/social-integration.md](docs/social-integration.md). It keeps API credentials in Actions secrets and generates public snapshots only in deployment artifacts.

# Daniel Santalla portfolio

Static export of the approved portfolio. No build step or ChatGPT runtime dependency.

GitHub Pages: publish the main branch root, or upload this directory with the official Pages Actions workflow. Root site repository `Danielsantalla.github.io` avoids subpath changes. No CNAME is included: DNS stays untouched until launch approval.

Staging is noindex. Before custom-domain cutover, restore index,follow for substantive pages, keep aliases/404 noindex, and verify canonical/sitemap origin. Local alias pages use HTML refresh because GitHub Pages does not support custom HTTP 301 rules.

Social counters stay hidden until populated with verified data. This export contains no API tokens, example comments, private development history or source code for games.

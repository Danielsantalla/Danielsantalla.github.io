A little pixel-art aquarium, built independently.

The project

Desktop Fishes is a pixel-art idle aquarium in which fish hatch, grow, interact and reproduce. I developed the project on my own in Unity.

My contribution

I worked on the game as a solo developer over approximately six months, bringing together the game’s art, behavior and implementation. Desktop Fishes was released in November 2025.

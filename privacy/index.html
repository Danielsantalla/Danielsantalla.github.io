Privacy and YouTube terms

Social statistics and conversations on tutorial pages.

Terms of use for YouTube features

By using this website and its YouTube-powered features, you agree to this privacy policy and agree to be bound by the YouTube Terms of Service. Public statistics and comments appear automatically from a snapshot hosted by this website. There is no separate acceptance button, social login, cookie or browser-storage preference for these features.

Public comments and statistics

Tutorial pages use the YouTube API to show public video statistics and comments, including author names, profile links, comment text and dates. X statistics and public replies come from the X API, including author names, usernames, profile images, text, dates and source links. Each platform is shown separately, with links to the original conversation.

YouTube snapshots are refreshed weekly and are not displayed after 14 days. X is a one-time imported snapshot with its import date shown, not a live feed. It is not automatically refreshed or hidden after 14 days. If a refresh or source is unavailable, some statistics or comments may be missing. This website does not collect a social login or offer a comment submission form. To comment, follow the link to the original platform.

YouTube data and external links

Comments display author initials rather than Google-hosted profile images. Displaying these statistics and comments does not load YouTube scripts or request images from Google. Following an external profile, comment or video link takes you to the relevant service, where its privacy policy applies.

See Google’s Privacy Policy and the YouTube Terms of Service.

X replies and profile images

X replies appear directly in this website’s layout, without embedded posts or X scripts. Loading an author’s profile image contacts X’s image server (pbs.twimg.com or abs.twimg.com), which receives your IP address. Images are requested without a referrer. Following an X profile or post link takes you to X. See X’s Privacy Policy.

Questions or removal requests

For questions about this display or to request removal of a cached comment or source, contact Daniel. Changes to an original comment are managed on YouTube or X. YouTube changes may appear after a refresh; the one-time X snapshot is maintained separately for removal requests and known source changes. Please report a changed or removed X comment so it can be removed promptly.

The Art Studio VR privacy policy covers that app separately.
